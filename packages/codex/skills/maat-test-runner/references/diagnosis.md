# Failure classification

- Setup/environment: server unreachable, driver missing, permission unavailable, device offline, signing or trust failure.
- Session lifecycle: Session creation/deletion, App activation/termination, browser launch, or cleanup failure.
- Locator/timing: target absent, ambiguous, stale, occluded, or not reached within framework waits.
- Assertion: the UI was observable but did not match the explicit expected business outcome.
- Product: repeatable mismatch with correct setup, stable locator, and supporting Evidence.

An exception alone rarely proves a product defect.
